Sample request: FrontierSWE-style and security tasks
A client wants to see samples before a new project starts. Two kinds of task: long-horizon software engineering tasks in the format of FrontierSWE, a public benchmark where an agent gets up to 20 hours on one problem (reimplementing a compiler or a database, optimising a codec, scientific computing), and cybersecurity or red-team tasks in the same format (security labs, incident response or forensics, web, IAM and cloud security, prompt injection, rogue-agent behavior, unauthorized tool use, or an agent breaking out of its system boundaries).

If you've already built one yourself, send up to three here by Friday 30 October, 12:00 ET. We review them as they arrive, so earlier is better.

There is no payment for samples and no guarantee of paid work. The client wants to see examples first. If they like yours, you'll be first in line when the project starts.

Only send work you own. No client or employer material, nothing built for another platform, nothing mostly generated by AI, no copies of FrontierSWE's own tasks, and no real credentials, live targets or undisclosed vulnerabilities.

BEFORE YOU SEND

The format

Read the FrontierSWE site and a few tasks in its GitHub repo. They are Harbor tasks.

One folder per task, laid out like the FrontierSWE tasks: instruction.md (what the agent is told), task.toml (agent and verifier time limits, resources), environment/ (Dockerfile and the starting workspace), a verifier (tests/test.sh, or environment/tests/ copied to a root-only path) that writes a score to /logs/verifier/reward.txt or reward.json, and solution/solve.sh (a reference solution that scores full marks).

The agent must not be able to read the solution or the hidden tests, and the score must come from running the agent's work, not from how it looks.

Three checks for every task

Run our checker on the folder and fix every FAIL. Its last line (FSWE-CHECK v1 PASS ...) goes in the form. Download the checker (Python 3.11+, no installs).
python3 frontierswe-check.py path/to/task
Run the reference solution with Harbor. It should print Mean: 1.000 (full marks).
harbor run -p path/to/task -a oracle
Run the empty agent. Doing nothing should print Mean: 0.000.
harbor run -p path/to/task -a nop
The form only takes a task with a PASS line, an oracle score above the empty-agent score, and an empty agent that scores 0.
